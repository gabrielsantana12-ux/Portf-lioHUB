# Como contribuir para o PortfolioHUB

Obrigado por seu interesse em contribuir com o PortfolioHUB! Este documento descreve o processo para colaborar com o projeto.

## 🐛 Reportando Bugs
1. Verifique se o bug já não foi reportado na aba de [Issues](../../issues).
2. Se não, abra uma nova Issue utilizando a tag `bug`.
3. Descreva o problema detalhadamente, incluindo passos para reproduzir, comportamento esperado e comportamento atual.

## ✨ Sugerindo Melhorias
1. Abra uma Issue com a tag `enhancement`.
2. Explique a nova funcionalidade ou melhoria. Descreva o porquê de ela ser útil para o portfólio.

## 💻 Fluxo de Desenvolvimento
1. Faça um *fork* deste repositório (ou crie uma branch se já for colaborador).
2. Crie uma branch para a sua alteração: `git checkout -b feature/minha-nova-funcionalidade`
3. Faça suas alterações e commite usando Conventional Commits: `git commit -m "feat: adiciona nova funcionalidade"`
4. Envie para o seu repositório: `git push origin feature/minha-nova-funcionalidade`
5. Abra um Pull Request detalhando suas alterações.

## 📋 Regras Gerais
* Siga as boas práticas de clean code.
* Não envie senhas, chaves de API ou dados sensíveis (PII) nos commits.
* Garanta que sua branch está atualizada com a `main` antes de abrir o PR.
