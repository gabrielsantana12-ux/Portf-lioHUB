# PortfolioHUB

O **PortfolioHUB** é uma plataforma centralizada e interativa projetada para exibir, gerenciar e armazenar projetos e portfólios digitais. Desenvolvido durante a disciplina Bootcamp I no CEUB, o projeto combina práticas avançadas de versionamento com Git e GitHub, hospedagem contínua via GitHub Pages, integração com ferramentas do Google Workspace e o suporte analítico da IA Google Gemini.

## 🎯 Objetivo
Proporcionar um ambiente profissional para apresentação de projetos acadêmicos e técnicos, aplicando conceitos rigorosos de gestão de usuários, controle de versão, fluxos colaborativos de trabalho e políticas de segurança da informação (incluindo conformidade com a LGPD).
